# Privacy Policy

_Last updated: October 29, 2026_

This policy covers the Brace – JSON Viewer Chrome extension ("the extension"), which formats JSON documents opened in Google Chrome.

## Data collection

The extension does **not** collect, transmit, sell or share any personal or sensitive user data.

- JSON you view is processed locally in your browser and never leaves your device.
- The extension makes no network requests and contains no analytics, tracking or advertising.

## Stored settings

The extension saves your display preferences (font, indent size and theme) using Chrome's built-in storage (`chrome.storage.sync`). If Chrome sync is turned on, Google syncs these settings across your signed-in browsers under [Google's Privacy Policy](https://policies.google.com/privacy). The developer has no access to them.

## Permissions

- **storage**: to save the display preferences described above.
- **Access to all sites**: so the extension can detect and format JSON on any URL. Pages that are not JSON are left untouched.

## Changes

Any changes to this policy will be posted on this page with an updated date.
